How to use: load a .sas or .sql file (it is read on your device, nothing is uploaded). The page detects whether it is SAS or SQL, and you can force one in the menu. Each box is a table and each arrow shows data going from one table to the next. Drag a box to move it (arrows follow). Click a box to light up everything it came from and everything made from it, and to see the lines where it is created and read; click a line number to jump to the code. Search lists every line with your word: click a result to jump there. Click a code line that creates a table to find its box. In SQL, tables made by CREATE TABLE/VIEW, INSERT, SELECT … INTO and MERGE become boxes, WITH names become purple boxes, and a loose SELECT becomes a “query” box. This is still a prototype: macro variables such as &yr. are shown as written, not resolved.
